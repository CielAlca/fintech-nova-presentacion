admin-panel y Configuración de NGINX

🧭 DNS Dinámico con resolver 127.0.0.11
Uso de variable set $upstream api-... para obligar a NGINX a consultar el DNS de Docker y no caerse si una API tarda en iniciar.

👤 LUCAS • RED INTERNA & PERSISTENCIA

Red fintech-net y MariaDB Unificada

🐳 Red User-Defined Bridge: fintech-net
Subred privada 172.18.0.0/16. Activa el servidor DNS embebido de Docker (127.0.0.11:53) para descubrir servicios por nombre.
🗄️ Aislamiento Lógico: 1 Motor, 5 Esquemas
Una sola instancia de MariaDB con 5 bases independientes (db_clientes, etc.). Evita saturar la memoria (5 motores consumirían >1.5 GiB).
💾 Named Volume vs Bind Mount (:ro)
• db_data: Persistencia permanente en /var/lib/mysql.
• init-scripts: Bind mount en solo lectura para inicialización SQL.

api-pagos y Resiliencia ante Caídas

🟢 Builds Deterministas con npm ci
Uso de --omit=dev --ignore-scripts: descarta dependencias de testing y bloquea ejecución de scripts maliciosos.
💵 Conversión Externa ARS $\rightarrow$ USD
